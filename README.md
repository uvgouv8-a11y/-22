# القناص – فلسفة ومنطق (أولى ثانوي)

تطبيق ويب بسيط (HTML/CSS/JS بدون أي مكتبات) فيه:

- **ملخصات**: ملخص المنهج كله مقسم أبواب، مع بحث وفلتر (الفلسفة / المنطق).
- **خريطة ذهنية**: شجرة قابلة للفتح والطي لكل المنهج.
- **اسأل القناص**: بتكتب سؤالك وتضغط إرسال فيفتح الواتساب بالسؤال جاهز.

## التشغيل
افتح `index.html` في المتصفح، أو شغّل `python3 -m http.server`.

## الرفع على GitHub Pages
1. أنشئ Repository جديد وارفع كل الملفات.
2. من **Settings ← Pages** اختر Branch `main` والفولدر `/ (root)` ثم Save.
3. الرابط هيظهر بعد دقيقة تقريبًا.

## التعديل
- رقم الواتساب وباقي الإعدادات: أول `data.js` (`CONFIG`).
- الملخصات والخريطة الذهنية: `SUMMARIES` و`MINDMAP` في `data.js`.
- الصورة: `assets/sniper.jpg` و`assets/icon.png`.
